# Phase 12：MCP 扩展体系实施路线

## 1. 交付阶段概览

- 对应里程碑：M3 开放生态与产品体验
- 版本升级：`0.9.0-SNAPSHOT` $\rightarrow$ `0.10.0-SNAPSHOT`
- 交付 Git Tag：`v0.10.0`
- 质量目标：全量测试 100% 绿灯，新增专项单测/契约测试，Zero Breaking Change

## 2. 详细任务执行清单

- [ ] **Task 1: 核心协议模型与 JSON-RPC 2.0 基础基线 (`com.xhlcli.mcp.protocol`, `model`)**
  - [ ] 实现领域实体：`McpServerConfig`, `McpServerStatus`, `McpToolDefinition`, `McpResource`, `McpResourceContent`, `McpContent`, `McpCallResult`
  - [ ] 实现 JSON-RPC 2.0 报文协议：`JsonRpcRequest`, `JsonRpcResponse`, `JsonRpcNotification`, `JsonRpcError` 及序列化适配
  - [ ] 编写协议序列化与反序列化测试 `JsonRpcProtocolTest`
- [ ] **Task 2: Transport 通道层实现 (`com.xhlcli.mcp.transport`)**
  - [ ] 定义 `McpTransport` 通用接口与生命周期契约
  - [ ] 实现 `StdioMcpTransport`（ProcessBuilder 进程派生、UTF-8 Stdin/Stdout 行通信、Stdout 非 JSON 防污染过滤、Stderr 环形诊断缓冲、取消信号传播）
  - [ ] 实现 `StreamableHttpMcpTransport`（基于 OkHttpClient 的 HTTP POST/SSE 通道、Header 与 Bearer 注入、超时与取消支持）
  - [ ] 编写 Transport 专项测试 `StdioMcpTransportTest` 与 `StreamableHttpMcpTransportTest`（使用模拟进程与 MockWebServer）
- [ ] **Task 3: MCP 协议客户端与能力协商 (`com.xhlcli.mcp.client`)**
  - [ ] 实现 `McpClient`：标准 `initialize` 握手、协议版本 `2024-11-05` 协商、`notifications/initialized` 发射
  - [ ] 实现工具操作：`tools/list` 与 `tools/call` 调用映射
  - [ ] 实现资源操作：`resources/list` 与 `resources/read` 内容读取
  - [ ] 实现通知监听：处理 `notifications/tools/list_changed` 与 `notifications/resources/list_changed`
  - [ ] 编写客户端契约测试 `McpClientTest`
- [ ] **Task 4: 两级配置合并与环境变量安全解析 (`com.xhlcli.mcp.config`)**
  - [ ] 实现 `McpConfigLoader`：读取并合并用户级 `~/.xhlcli/mcp.json` 与工作区 `.xhlcli/mcp.json`（工作区同名优先）
  - [ ] 实现 `${VAR}` 安全解析器：仅从受信环境变量与 `.env` 中展开，缺失变量时置为 `ERROR` 状态并不影响其他 Server
  - [ ] 编写配置加载测试 `McpConfigLoaderTest`
- [ ] **Task 5: 动态工具适配与安全审批审计集成 (`com.xhlcli.mcp.tool`, `hitl`)**
  - [ ] 实现 `McpToolAdapter`：实现 `com.xhlcli.tool.Tool` 接口，命名空间 `mcp__{server}__{tool}`
  - [ ] 实现 Schema 清洗：补全缺失的 object root 与 properties 结构
  - [ ] 实现调用结果转换：文本拼接、多模态图片元数据脱敏摘要转换 `[Image: mimeType=..., size=...]`
  - [ ] 扩展 `ApprovalPolicy` 与 `AuditLog`：将 `mcp__` 工具纳入分级审批与敏感凭据脱敏审计
  - [ ] 编写工具适配测试 `McpToolAdapterTest` 与审批集成测试
- [ ] **Task 6: 服务生命周期管理器与动态注册 (`com.xhlcli.mcp.manager`, `tool`)**
  - [ ] 实现 `McpServerManager`：统筹 Server 生命周期（启停、重启、禁用、启用），支持异步启动超时预算（默认 3s）
  - [ ] 实现工具动态注入与热刷新：在 Server 就绪或工具变更时无感刷新 `ReactAgent`、`PlanExecuteAgent`、`TeamOrchestrator`
  - [ ] 编写生命周期与并发隔离测试 `McpServerManagerTest`
- [ ] **Task 7: 终端交互命令集成 (`com.xhlcli.cli`)**
  - [ ] 扩展 `ChatCommand` 与 `ChatCommandParser` 支持 `/mcp` 及其子命令（`list`, `status`, `tools`, `resources`, `read`, `restart`, `stop`, `start`, `logs`）
  - [ ] 改造 `ChatLoop` 与 `PlainRunRenderer` 渲染 `/mcp` 指令输出与帮助手册
  - [ ] 更新 `ChatBootstrap`：装配 `McpServerManager`，在首屏执行轻量启动并挂载命令
  - [ ] 编写集成测试 `McpCliIntegrationTest`
- [ ] **Task 8: 全量验证、物证报告与 Release 发布 (DoD 铁律)**
  - [ ] 运行 `./mvnw clean verify` 确保全量测试 100% 绿灯
  - [ ] 产出评测报告 `docs/engineering/mcp-evaluation.md`
  - [ ] 更新 Living Docs: `docs/PROJECT.md`, `docs/ROADMAP.md`, `docs/TECH_DESIGN.md`, `docs/specs/README.md`, `docs/plans/README.md`, `CHANGELOG.md`, `AGENTS.md`
  - [ ] 升级 `pom.xml` 为 `0.10.0-SNAPSHOT`，执行 Git 提交、打 Tag `v0.10.0` 并推送到 GitHub

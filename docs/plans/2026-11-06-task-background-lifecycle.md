# task 后台任务可靠性优化实施计划

本次目标是让用户提交只读后台分析后继续前台对话，并能可靠查询、取消、重启后查看结果。依据为 2026-11-06 用户明确授权的 task 优化、文档沉淀和远程同步；不代表整个 v1.1 发布。验证事实统一记录在 `docs/engineering/task-background-lifecycle-verification.md`。

## 1. 范围与技术基线

- 复用 Java 21、Maven Wrapper、JUnit 5.10.2、SQLite JDBC 3.49.1.0、JLine 4.3.1、现有 ReAct 和安全执行器；版本依据 `pom.xml`，无新增依赖。
- 修改 `runtime/task`、CLI task 装配和相关测试、文档。保留 Runtime HTTP API 的字符串 TaskRunner 契约；不改 Team、快照恢复和会话压缩。
- 每个后台任务独立历史、取消令牌、工具与预算。后台只开放明确的本地只读工具和网页读取工具，不继承前台人工授权，不自动运行 Shell、写文件或动态 MCP 工具。
- CLI 退出后不承诺继续运行；结果持久保存。崩溃遗留任务标记失败并说明结果不确定，不自动重放。
- 基于现有 `runtime_tasks` 表和 `workspace` 字段；不增删表、字段或索引，不迁移旧库。缺少必需列的旧库拒绝启用 task 并给出诊断，历史数据不动。
- 本次同步目标为 origin/main；只提交本任务内容，不打 Tag、不发布 Release、不部署。原工作区存在其他未提交改动，使用独立 Git 工作区完成实现与验证。

## 2. 执行方案与取舍

操作系统文件锁是进程存活期间独占文件的机制。本次每项执行持有一把锁，直到执行和清理结束；另一实例无法领取或恢复仍持锁的任务。SQLite 条件更新负责防止完成、取消竞争覆盖终态。数据库路径和工作区根均规范化，所有读写限定工作区。

采用本机文件锁而非新增 owner/lease 数据列，因为产品目前为单机 CLI，不需要跨主机调度；文件锁可以直接检验持有者是否仍活跃，无需迁移、心跳过期和时钟推断。只支持本机文件系统；不同版本进程不得同时打开同一个任务库。锁文件不能在运行期间删除。

运行中取消先持久化 `cancel_requested`（取消已请求）；控制线程将取消令牌传播到实际执行，等待工具真实退出后才提交 `canceled`（已停止）。排队任务可直接取消。停止不撤销已完成操作，不能承诺撤回远端已受理请求。

任务开始时使用当前 CLI 模型配置与项目规则，独立创建 Agent，不复制前台聊天；后台只读工具执行器统计实际在途调用，避免 Agent 超时返回后错误宣称所有工具已退出。运行输出经脱敏后保存为当前结果，完成后以最终结果替换。后台通知只包含任务 ID、终态和查询入口。后台暂不自动摘要，每轮检查消息与工具的估算预算，超限明确失败；文本搜索注入纯 Java 引擎，不开放可能启动外部驱动的 Git diff。

## 3. 任务与文件映射

| 任务 | 交付 | 文件范围 | 依赖 |
|---|---|---|---|
| T1 | 工作区隔离、唯一领取、失联恢复与重启读取 | DurableTaskManager、文件锁辅助类及真实 SQLite 测试 | 基线确认 |
| T2 | 结构化结果、跨实例取消、关闭清理 | 任务执行上下文/结果、状态枚举、manager 测试 | T1 |
| T3 | 独立后台 Agent、只读工具、输出隔离 | 后台 runner、受管理工具执行器、ChatBootstrap/ChatLoop | T2 |
| T4 | 命令提示、完成通知、完整交付文档 | TaskCommandFormatter、README、TECH_DESIGN、PROGRESS、验证文档 | T3 |
| T5 | 真实入口验收、审查、打包、同步远程 | 集成测试、临时模拟模型、Git | T4 |

按 T1→T2→T3→T4→T5 串行推进；现有任务模块测试先运行，新增回归先证明失败。实际结果不在计划中重复维护。

## 5. 验证与交付

相关测试用 `./mvnw -Dtest='*Task*Test' test`，最终使用 `./mvnw verify` 执行项目完整检查和打包；CLI 真实入口接临时本地模拟模型服务验证，避免调用用户真实付费服务或任务库。人工验收写明 Java、构建、模型配置、CLI 命令与预期结果，不虚构页面入口。

代码恢复使用本次提交的逆向提交；任务库无 Schema 迁移。退回旧版本前须停止所有新版任务，不能混跑新旧调度器；取消请求和失联状态应先检查，不依赖旧版自动恢复。同步前核对远程变动并正常整合，禁止强推和覆盖用户已有工作。

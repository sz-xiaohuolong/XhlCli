# Phase 18: 开源发布治理与静态官网工程评测报告

## 1. 阶段目标与交付全景

Phase 18 是 XhlCLI 走向正式开源发布（`v1.0.0`）的关键里程碑。本阶段聚焦于：
1. **现代化静态官网 (`website/`)**：遵循 `/impeccable` 严格设计规约（Persuade 模式、零容忍禁忌：无 kicker、无渐变字、无劣质卡片堆砌、无系统 Emoji、真实代码切片、浏览器表面主题化），构建具备高度工程美学与沉浸感的官网；
2. **交互式终端模拟器 (Terminal Simulator)**：高保真模拟 JLine 4 动态终端交互，支持 `/team`（多智能体流水线）、`/restore`（隔离快照还原）、`@image`（视觉防御护栏）、`/task`（后台持久任务与 Runtime API）4 大场景逐行打字动画；
3. **交互式指令速查表 (Interactive Cheat Sheet)**：涵盖全部 18 个演进阶段的 20 项生产级指令，支持多类别标签过滤、实时模糊搜索与毫秒级一键复制；
4. **Vercel 零配置秒级部署**：提供 `website/vercel.json` 与根目录 `vercel.json`，纯原生 HTML5/CSS3/Vanilla JS，零 npm 依赖与零服务端负担，一键直连 Vercel 静态托管；
5. **开源一键安装脚本 (`install.sh`)**：全自动系统与架构探测、Java 21 运行时就绪校验、启动器包装软链与 PATH 配置引导；
6. **全量回归与正式发版**：版本升级至 `1.0.0`，全量 522+ 单元与集成测试 100% 绿灯。

## 2. 设计系统与 Craft Floor 合规审计

严格执行 `/impeccable` 设计规范，逐项验证如下：

| 审计项目 | 规范要求 | 实际实现与验证 | 判定 |
| :--- | :--- | :--- | :--- |
| **Kicker / Eyebrow 禁忌** | 严禁在标题上方添加无实质意义的分类小胶囊 | 官网全页所有标题均直接表达核心价值，无多余装饰性 Eyebrow | **PASS** |
| **渐变字体禁忌** | 严禁滥用 Gradient Text | 所有标题与文字依靠字重（800/700）、字阶与高对比度排版表达视觉层级 | **PASS** |
| **系统 Emoji 图标禁忌** | 严禁用普通 Emoji 充当 UI 按钮或卡片图标 | 全部使用一致描边（1.5px~2px）的专业矢量 SVG 图标 | **PASS** |
| **卡片布局同质化禁忌** | 严禁千篇一律的居中 3 卡片对齐 | 采用异构 Bento Grid（包含 span-2 跨列卡片与真实 Java 源码切片） | **PASS** |
| **浏览器表面定制** | 定制 Selection、滚动条、Favicon 与主题色 | 定制深黑橙焰 `::selection`、极简深色细滚动条、专属流线龙焰矢量 Favicon | **PASS** |
| **零第三方运行时依赖** | 严禁引入不必要的重量级 JS 库 | 纯 Vanilla JS (零 React/Vue/jQuery/Tailwind 构建运行时)，极速加载 | **PASS** |

## 3. 核心功能与交互验证

### 3.1 交互式终端模拟器
- **场景覆盖**：
  1. `/team`：展示 Kahn 拓扑排序、有界并发调度（Workers 并行分析与打补丁）及 Reviewer 专职审查；
  2. `/restore`：展示误删核心文件时，通过 SideGit 独立裸仓库毫秒级原子还原，且宿主 Git 零污染；
  3. `@image`：展示透明通道白底平铺、双三次保真缩放与纯文本模型（DeepSeek）优雅降级防 400；
  4. `/task`：展示 SQLite 任务入队与 Localhost Runtime API (127.0.0.1:8765) SSE 游标事件流。
- **动效体验**：逐行时间差渲染、模拟终端光标呼吸闪烁、支持随时点击「重播」或切换 Tab。

### 3.2 一键安装切换器
- 支持 macOS/Linux (curl)、Homebrew (brew)、Windows (PowerShell) 与源码构建 (Maven) 4 种模式一键切换并同步更新复制文本；
- 复制按钮具备状态反馈（打钩 + "已复制" + 2秒自动恢复）。

### 3.3 交互式指令速查表
- 动态过滤：支持按多智能体、快照、后台任务、多模态、系统配置分流；
- 实时搜索：输入关键词时，同步更新指令条数徽章与高亮匹配行；
- 行内复制：每行均包含独立复制按钮，点击即通过 `navigator.clipboard` 写入并触发底部平滑 Toast。

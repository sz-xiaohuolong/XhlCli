# Phase 07：代码库 RAG PRD

> 优先级：P1
> 状态：已规划
> 前置阶段：Phase 05、06
> 对应里程碑：M2 复杂任务智能

## 1. 阶段目标

建设面向代码仓库的增量语义检索能力，用于自然语言描述、跨文件概念和精确搜索难以命中的任务。RAG 是实时精确搜索的补充，不取代 `glob/grep/read` 主路径。

## 2. 用户价值

- 用户可以用业务语言询问“订单取消逻辑”而不必知道类名。
- 大型仓库只召回与当前任务相关的代码片段，减少无关上下文。
- 索引可复用并随文件变化增量更新，不需要每次全量重建。

## 3. 用户故事

- 作为开发者，我希望用自然语言找到跨多个模块实现的业务能力。
- 作为开发者，我希望检索结果带文件、符号、行范围和相似度依据。
- 作为维护者，我希望可以查看索引状态、更新失败和资源占用。

## 4. 本期范围

- 代码文件发现、语言识别和忽略规则。
- 文件、类型、方法或受控窗口粒度的代码切分。
- Embedding Provider 接口及一个默认实现。
- 本地向量与元数据持久化。
- 文件哈希驱动的增量新增、更新和删除。
- Top-K 检索、阈值、去重、邻接片段扩展和上下文组装。
- `/index`、`/index status`、`/index clean`、`/search`。
- RAG Golden Set、召回率和噪声评估。

## 5. 功能需求

### FR-07-01 代码切分

代码块必须保留项目相对路径、语言、起止行、符号名、父级符号、内容哈希和原始文本。优先按语义结构切分，解析失败时使用有重叠的行窗口降级。

### FR-07-02 索引范围

默认遵循项目根、`.gitignore`、支持语言和文件大小限制。生成文件、依赖目录、二进制和敏感配置默认不进入索引。

### FR-07-03 增量索引

索引时比较文件哈希：新增文件写入新块，修改文件只替换对应块，删除文件移除旧块，未变化文件不请求 Embedding。

### FR-07-04 可恢复构建

单个文件解析或 Embedding 失败不破坏已有可用索引。索引状态显示已完成、跳过、失败和剩余数量，用户可重试失败项。

### FR-07-05 语义检索

查询返回排序后的代码块、分数和来源。低于阈值时明确表示证据不足，不能用低相关片段拼凑答案。

### FR-07-06 去重与上下文组装

相邻或重叠片段合并，重复内容按来源去重。在预算内优先保留高相关、不同文件且能解释关系的片段。

### FR-07-07 Agent 使用策略

自然语言意图模糊、关键词未知、跨模块概念或精确搜索无结果时使用 RAG。返回候选后，Agent 应通过 `read_file` 验证最新代码再修改。

### FR-07-08 索引可观察性

用户可以查看索引位置、版本、Embedding 模型、维度、文件数、块数、更新时间、失败数和估算空间。

### FR-07-09 索引兼容性

切分策略、Embedding 模型或向量维度变化时检测不兼容，并提示重建，不得混用不一致向量。

## 6. 非目标

- 不自动索引项目根之外的依赖源码。
- 不把向量分数当作事实正确性。
- 不在本期实现通用知识库或文档问答平台。
- 不要求支持所有编程语言的 AST 解析。
- 不将索引文件提交到 Git。

## 7. 异常与边界场景

- Embedding 服务不可用时保留精确搜索能力，并显示 RAG 降级状态。
- 大仓库首次索引可取消，取消后已提交批次保持一致。
- 文件在索引期间变化时该文件标记待重试。
- 查询空白、过长或只含符号时进行规范化或拒绝。
- 多个相似生成文件不能挤占全部 Top-K 名额。

## 8. 非功能要求

- 默认索引在本地持久化，存储写入具备事务边界。
- 10,000 个代码块规模下，向量检索目标在 1 秒内返回候选，不包含远程 Embedding 延迟。
- 索引进度可流式展示且不阻塞终端取消。
- 检索结果必须可追溯到当前文件内容。

## 9. 验收标准

1. Golden Set 的业务语义查询达到预先记录的 Recall@K 基线。
2. 修改一个文件后，增量索引只处理该文件并替换旧片段。
3. 删除文件后检索不再返回其旧片段。
4. Embedding 服务不可用时 Agent 自动回到精确搜索路径。
5. Agent 在修改候选文件前会读取当前文件验证结果。
6. 不兼容索引被识别并要求重建，不发生静默错误。

## 10. 测试与验证

- 单元测试：切分、哈希、去重、阈值和预算组装。
- 集成测试：SQLite 或等价存储事务、增量新增/更新/删除。
- Golden Set：自然语言查询到期望模块的 Recall@K。
- 手工演示：业务语言定位跨模块代码并引用真实行范围。

## 11. GitHub 交付物

- 可公开的小型评测仓库与查询集。
- 全量与增量索引耗时、召回率和存储占用报告。
- 文档明确说明精确搜索与 RAG 的使用边界。

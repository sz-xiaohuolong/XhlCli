# Phase 13：Web 与浏览器 PRD

> 优先级：P1
> 状态：已规划
> 前置阶段：Phase 04、12
> 对应里程碑：M3 开放生态与产品体验

## 1. 阶段目标

为需要最新公开信息、已知网页内容或 JavaScript 渲染页面的任务提供分层联网能力。Agent 根据场景在搜索、轻量正文获取和浏览器交互之间选择，并对网络目标、登录态和敏感页面执行更严格的权限策略。

## 2. 用户价值

- 用户可以让 Agent 查询当前官方文档、版本信息和公开网页。
- 普通网页使用轻量获取，复杂页面才启用浏览器，降低成本和干扰。
- 使用登录态浏览器时，用户清楚知道连接模式和敏感操作风险。

## 3. 工具选择路径

```text
需要发现页面 → web_search
已知公开 URL → web_fetch
SPA / 交互 / 防爬失败 → browser snapshot
需要点击或输入 → 浏览器写操作 + 审批
需要登录态 → 用户确认后连接共享会话
```

## 4. 本期范围

- `web_search` Provider 抽象与一个默认实现。
- `web_fetch`：HTTP 获取、正文抽取、Markdown 输出。
- URL 和网络策略：协议、私网、重定向、大小、超时和限流。
- 通过 MCP 接入浏览器快照、导航、点击和表单能力。
- 隔离浏览器与用户授权共享会话模式。
- 敏感页面与浏览器操作审批。
- 页面来源、获取时间和引用信息。

## 5. 功能需求

### FR-13-01 联网决策

只有用户明确要求联网、问题具有时效性或本地上下文不足时才使用 Web。当前项目和当前代码问题默认使用本地工具。

### FR-13-02 搜索

搜索结果包含标题、URL、摘要和可用时间信息，并限制数量。搜索结果只是候选来源，重要结论应继续打开页面验证。

### FR-13-03 正文获取

对已知 URL 获取 HTTP 内容，限制协议、重定向次数、响应大小和超时。HTML 转换为保留标题、段落、列表、表格和链接的简洁 Markdown。

### FR-13-04 网络安全

默认拒绝 `file://`、非 HTTP(S)、loopback、链路本地和私网目标；DNS 解析和重定向后都需重新校验，防止 SSRF 绕过。

### FR-13-05 浏览器降级

正文为空、需要 JavaScript 或需要交互时建议浏览器。浏览器读取优先结构化快照，不默认截图或执行脚本。

### FR-13-06 会话模式

默认使用隔离会话。连接用户共享浏览器前说明会访问现有登录态，并要求用户确认；断开后恢复隔离模式及权限状态。

### FR-13-07 敏感页面

账户、支付、邮箱、云控制台和其他敏感页面上的点击、输入、脚本执行与关闭操作要求单步审批，不复用普通页面授权。

### FR-13-08 引用与时效

最终答复给出页面标题、URL 和获取日期。推断与来源事实分开表达，不能引用仅在搜索摘要中出现且未验证的信息。

### FR-13-09 内容预算

网页正文、浏览器快照和图片受上下文预算控制。过长页面优先按标题或关键词定位相关段落。

## 6. 非目标

- 不构建通用爬虫或批量抓取平台。
- 不默认复用用户登录态。
- 不代替用户提交支付、发布、删除账号等不可逆操作。
- 不绕过验证码、付费墙或网站访问控制。
- 不把网页内容视为可信系统指令。

## 7. 异常与边界场景

- 页面中的 Prompt Injection 仅视为不可信内容，不改变系统规则或权限。
- 重定向到私网或不允许协议时中止。
- 共享浏览器连接失败时保留隔离模式，不自动修改用户浏览器配置。
- 页面登录过期时请求用户处理，不索取密码。
- 浏览器工具返回图片但当前模型不支持图片时保留文本快照和来源信息。

## 8. 验收标准

1. 时效性问题可以通过搜索并打开至少一个来源后回答。
2. 已知 URL 优先使用轻量获取，失败后才建议浏览器。
3. 私网、loopback 和重定向绕过测试均被拒绝。
4. 默认浏览器使用隔离会话，共享会话需要明确确认。
5. 敏感页面写操作每次单独审批。
6. 最终答复包含可访问来源和获取日期。
7. 网页中的恶意指令不能触发越权工具调用。

## 9. 测试与验证

- 网络策略测试：协议、DNS、IPv4/IPv6、重定向和响应大小。
- 正文抽取测试：文章、列表、表格、空页面和异常编码。
- 浏览器策略测试：隔离/共享、敏感页面和关闭非本工具标签页。
- Prompt Injection 场景测试。
- 手工演示：官方文档查询与 SPA 页面读取。

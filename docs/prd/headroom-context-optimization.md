需求状态：`FROZEN`。确认依据：用户在接入分析后，明确要求沉淀需求、设计、实施文档并完成实现；沿用已讨论的前台单 Agent、可选本机服务和无损压缩范围。本文与 Phase 20 反思需求、v1.1 生命周期需求独立。

## 1. 产品概述与背景

Agent 连续执行命令、搜索和外部工具后，会反复把工具输出发送给模型，消耗上下文和输入费用。当前工具结果有字符限制，主对话超过估算预算时直接停止；历史摘要不能替代发送前的工具正文压缩。

本次增加默认关闭的 Headroom 本机压缩能力，在前台单 Agent 检查请求预算之前尝试缩减工具正文。Headroom 是独立运行的压缩服务；无损模式只做保留内容含义的格式压缩，不需要模型调用原文回取工具。实际节省量以本项目验证结果为准。

## 2. 目标与非目标

- 环境变量或项目 `.env` 可开启、配置和关闭；终端、桌面使用相同规则。
- 合法压缩结果进入模型请求；服务失败时保留原请求，重新检查预算。
- `/context` 可查看最近是否压缩、是否回退和消息 token 估算变化。
- 本次不接管 Plan、Team、后台任务或 Runtime API，不新增桌面设置页面，不捆绑安装或自动启动 Python 服务。
- 不启用有损压缩、CCR 原文回取、Headroom 记忆、学习或回答改写；不改变已有工具输出字符限制，不承诺固定节省比例或模型质量提升。

## 3. 用户与场景

使用终端或桌面普通聊天执行多轮工具任务的开发者。优先场景为构建日志、搜索结果和 JSON 文本；源码原文、补丁和技能指令需要原样保留。

## 5. 详细行为与验收

### REQ-H01：开启与配置

进程环境变量优先于项目 `.env`。默认关闭时不访问服务；开启时仅允许回环地址，禁止重定向，模型 API Key 不发送给 Headroom。变量与限制见方案第 4 节。CLI 启动、桌面下一轮创建 Agent 时读取配置。

| 验收 | 给定—操作—结果 |
|---|---|
| AC-H01 | 未开启时运行普通任务，不请求压缩服务，已有模型调用行为保持 |
| AC-H02 | 合法配置在终端和桌面生效；非法开关、非回环地址或非法超时得到中文配置错误，不回显敏感输入 |

### REQ-H02：压缩与保护

每轮模型请求使用同一份工具定义快照。工具观察结果的 `summary` 为正文，`data`、执行状态等其他字段及其数值含义保持不变，不要求 JSON 空白和数字字面格式相同；旧纯文本工具消息可直接作为正文。只选择已知调用对应的正文，排除源码读取、写入、补丁、diff、技能和快照恢复工具，以及有图片或未知结构的消息。只采用结构检查通过、确实更短的结果。

压缩服务只收到选中正文、工具名及合成调用 ID，不收到用户输入、系统规则、assistant 正文、推理、图片、真实调用参数或凭据。压缩后组装记忆，并检查最终消息及工具定义的预算；不写回原始历史。

| 验收 | 给定—操作—结果 |
|---|---|
| AC-H03 | 合法结果更短时模型收到压缩正文；历史、当前输入、规则、推理、图片、调用 ID、参数、观察控制字段保持 |
| AC-H04 | 受保护消息或无正文时跳过；增加、删除、重排消息、改变调用关联或产生回取标记时拒绝结果 |
| AC-H05 | 原历史超预算而压缩后在预算内时可继续；压缩结果、记忆和 schema 合计仍超限则返回 `CONTEXT_BUDGET`，不请求模型 |

### REQ-H03：失败与取消

超时、连接失败、非成功状态、过大或畸形响应均回退原请求，不自动重试，不向模型注入异常正文。回退后仍超预算则停止。用户取消或整体超时会取消压缩 HTTP 调用，之后不得继续请求模型；失败不能清空、摘要化或修改历史。

| 验收 | 给定—操作—结果 |
|---|---|
| AC-H06 | 服务关闭、超时、报错或返回畸形内容，预算允许则发送原正文，预算不允许则停止；诊断只记录固定原因 |
| AC-H07 | 压缩期间取消或整体超时，HTTP 调用退出，模型不开始，运行保持取消或超时终态 |

### REQ-H04：诊断

`/context` 显示开关、最近一次尝试的状态、消息 token 估算前后值、变更正文条数及耗时。估算不代表 Provider 账单，也不证明模型已收到请求。桌面保留诊断元数据供后续查看，不保存压缩正文；旧聊天缺少记录仍可使用。

| 验收 | 给定—操作—结果 |
|---|---|
| AC-H08 | 终端、桌面工具任务后执行 `/context`，可见尝试状态和估算；关闭或无记录时明确说明 |
| AC-H09 | 桌面重启后仍可读诊断，原历史保留，旧聊天兼容，切换模型后使用当前模型信息 |

### REQ-H05：交付

| 验收 | 给定—操作—结果 |
|---|---|
| AC-H10 | 按说明启动固定版本的真实 Headroom，验证压缩接口及集成；区分真实服务、模拟模型、真实模型验证 |
| AC-H11 | 按说明关闭并重启 CLI 或发起桌面下一轮，恢复原路径；文档列出环境、命令、输入、观察位置和预期 |

## 6. 交互要求

沿用普通聊天、取消和 `/context`，不新增设置页面。无工具正文时显示跳过或无记录；故障时诊断解释回退；极限输入经预算检查停止。压缩等待属于本轮任务，可用现有停止操作取消。

## 7. 限制与边界

无损压缩不保证所有文本都变小；已被工具字符限制删除的内容不能恢复。本次仅访问本机回环，不新增外部数据发送权限、数据库迁移或后台进程管理。

## 8. 统计与隐私

只保留固定状态、原因、估算、条数和耗时，不新增分析平台或原文日志。Headroom 自身统计的禁用方式在启动说明中交代。

## 9. 待决问题与风险

Open Questions：`None`。接口、超时和体积限制是实施选择，由方案维护。上游接口变化、实际节省较小和服务不在线通过固定验证版本、响应检查、回退及真实服务验证处理。离线测试不证明真实模型质量、费用或其他机器兼容性。

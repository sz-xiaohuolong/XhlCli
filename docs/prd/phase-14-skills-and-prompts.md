# Phase 14：Skill 与 Prompt 分层 PRD

> 优先级：P1
> 状态：已规划
> 前置阶段：Phase 05、12
> 对应里程碑：M3 开放生态与产品体验

## 1. 阶段目标

将 Agent 的稳定行为规则、模式差异、项目上下文和场景专家知识分层管理。通过按需 Skill 加载减少系统 Prompt 膨胀，让用户和项目可以安全覆盖提示内容，而不修改 Java 代码。

## 2. 用户价值

- 用户可以把重复的工作方法沉淀为可复用 Skill。
- Agent 只在任务匹配时加载详细说明，节省上下文。
- 项目团队可以提交共享规则，个人可以保留本地覆盖。

## 3. Prompt 分层

推荐逻辑顺序：

```text
基础身份与语言
  → 工具与安全规则
  → 运行模式
  → 当前日期、模型和项目
  → 项目规则与检索记忆
  → Skill 索引/按需正文
  → 上下文管理与交接要求
```

安全底线不能被项目或用户覆盖取消。

## 4. Skill 结构

每个 Skill 是独立目录，至少包含带元数据的 `SKILL.md`，可选包含 `references/`、`scripts/` 和 `assets/`。元数据至少包含名称、描述和适用场景。

## 5. 本期范围

- Prompt 文件化、分层组装和版本标识。
- 内置、用户级、项目级三层覆盖。
- Skill 发现、索引、启停、查看和重新加载。
- `load_skill` 按需加载与下一轮注入。
- Skill 正文、参考资料和脚本边界。
- Prompt 导出、审计与 Golden Test。
- 一个内置 Coding Workflow Skill 和一个 Web Research Skill。

## 6. 功能需求

### FR-14-01 分层组装

每层 Prompt 有单一职责、确定顺序和独立预算。缺少必需基础层时启动失败；可选层失败时告警并降级。

### FR-14-02 覆盖规则

优先级为内置 < 用户级 < 项目级。覆盖按完整文件或明确块进行，不进行难以预测的模糊文本合并。系统安全层不可覆盖。

### FR-14-03 Skill 索引

启动时只把启用 Skill 的名称和简短描述注入索引，并限制数量与总长度。详细正文不默认进入系统 Prompt。

### FR-14-04 按需加载

Agent 判断任务匹配后调用 `load_skill(name)`。Skill 内容在受控预算内注入下一轮，并在当前 Run 中避免重复加载。

### FR-14-05 Skill 管理

提供列出、查看、启用、禁用和重载命令。解析失败的 Skill 不阻塞其他 Skill，状态中显示具体错误。

### FR-14-06 参考资料

Skill 可以指向相对路径参考文件。读取必须限制在 Skill 目录内并按需进行，避免启动时加载全部资源。

### FR-14-07 脚本安全

Skill 附带脚本不自动执行。执行时仍作为命令工具经过参数校验、权限审批和审计。

### FR-14-08 Prompt 可审计

用户可导出当前会话实际组装的系统 Prompt；导出前脱敏本地凭据和不应公开的配置。输出标注各层来源和截断状态。

### FR-14-09 变更评测

核心 Prompt 和 Skill 变更需运行固定任务集，对工具选择、越权率、完成率和 Token 使用进行对比。

## 7. 非目标

- 不建立在线 Skill 市场。
- 不允许 Skill 绕过权限和系统规则。
- 不支持任意 YAML 语法；只实现文档明确的元数据子集。
- 不把所有使用经验写进基础系统 Prompt。
- 不因 Skill 匹配就自动执行其脚本。

## 8. 异常与边界场景

- 同名 Skill 按层级整体覆盖，并显示实际来源。
- Skill 描述过长或数量过多时按确定策略截断索引。
- 引用路径逃逸 Skill 目录时拒绝。
- Skill 加载后模型未使用时不自动重复注入后续所有 Run。
- 导出 Prompt 时项目规则中的疑似密钥同样脱敏。

## 9. 验收标准

1. Prompt 各层来源、顺序和预算可通过导出验证。
2. 同名项目级 Skill 正确覆盖用户级和内置版本。
3. 未匹配 Skill 仅注入索引，匹配后才加载正文。
4. Skill 脚本调用仍触发正常审批和审计。
5. 解析失败或非法引用不会阻塞其他 Skill。
6. Prompt 变更前后可以运行同一评测集并比较结果。

## 10. 测试与验证

- 单元测试：分层顺序、覆盖、预算、元数据解析和路径限制。
- Golden Test：固定上下文下组装结果及关键安全规则存在性。
- 场景测试：按需加载、重复加载、禁用和重载。
- 手工演示：项目 Skill 指导完成特定工作流。

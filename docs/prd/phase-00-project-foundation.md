# Phase 00：项目基线 PRD

> 优先级：P0
> 状态：已规划
> 前置阶段：无
> 对应里程碑：M0 可运行基础

## 1. 阶段目标

建立 XhlCLI 从需求到实现的项目基线，使后续每一期都能在统一的文档、版本、测试和提交规范下开发。本期结束时，仓库应具备可编译、可测试、可运行的最小 Java 21 命令行骨架，但不包含真实模型对话和 Agent 能力。

## 2. 用户价值

- 开发者克隆仓库后可以用一条命令验证环境和项目骨架。
- 贡献者能够快速理解产品目标、目录结构、开发规则和当前进度。
- AI 编程工具获得稳定、明确的项目上下文，减少后续阶段的无关修改。

## 3. 用户故事

- 作为首次参与的开发者，我希望按照 README 在 10 分钟内启动项目，以确认环境正确。
- 作为维护者，我希望需求、技术设计和开发规则职责分离，以便需求变化时可追踪。
- 作为 AI 编程工具，我希望获得准确的构建、测试和修改约束，以便只在允许范围内工作。

## 4. 本期范围

### 4.1 产品文档

- 总 PRD 与 Phase 00–18 子 PRD 索引。
- `RESEARCH.md`，记录用户问题、竞品观察、参考资料和待验证假设。
- `TECH_DESIGN.md` 初始版本，仅覆盖项目骨架和全局技术原则。
- `AGENTS.md`，定义仓库导航、开发规范、测试命令和安全边界。
- `ROADMAP.md`，区分已交付、开发中和计划能力。
- `CHANGELOG.md`，采用可持续维护的版本记录格式。

### 4.2 工程骨架

- Java 21 和 Maven 项目。
- 可运行的 `xhlcli` 命令入口。
- `--help` 与 `--version` 两个基础参数。
- 源码、资源、单元测试和集成测试目录。
- 基础日志、配置和异常边界的目录占位，但不提前实现后续业务。
- 持续集成执行编译和测试。

### 4.3 开源基础

- README、LICENSE、贡献指南和行为准则。
- `.gitignore` 排除密钥、本地状态、日志和构建产物。
- Issue 与 Pull Request 模板。

## 5. 功能需求

### FR-00-01 环境检查

构建系统必须明确拒绝低于 Java 21 的运行环境，并输出可理解的升级提示。

### FR-00-02 命令入口

执行构建产物时必须进入统一 CLI 入口。无参数时显示产品简介和下一步提示；`--help` 输出可用参数；`--version` 输出单一版本来源中的版本号。

### FR-00-03 配置隔离

示例配置可以提交到仓库，真实 API Key、本地会话、缓存、索引、日志和快照不得被 Git 跟踪。

### FR-00-04 文档状态

README 与 Roadmap 必须明确区分“已交付”“开发中”“计划中”。尚未通过验收的阶段不得出现在已交付功能列表。

### FR-00-05 自动验证

持续集成必须在受支持的操作系统上运行编译和测试，并在失败时阻止合并。

## 6. 非目标

- 不接入真实模型。
- 不实现 Agent 循环、文件工具或 TUI。
- 不建立面向未知需求的复杂模块系统。
- 不在本期确定所有后续阶段的类和接口。

## 7. 体验要求

- 首次运行失败时，错误信息应包含原因和下一步动作。
- `--help` 文案面向使用者，不暴露内部类名。
- 默认输出不包含调试堆栈；调试模式可以显示详细信息。

## 8. 验收标准

1. 在 Java 21 环境执行标准构建命令成功产生可运行产物。
2. `--help`、`--version` 和无参数启动均有确定输出及自动测试。
3. README 能让新用户完成环境检查、构建和运行。
4. 仓库中不存在真实密钥、构建产物或本地运行状态。
5. 文档链接有效，Roadmap 没有把计划能力表述为已完成。
6. CI 在至少一个 Linux 环境完成编译和测试。

## 9. 测试与验证

- 单元测试：版本读取、参数解析和错误信息。
- 集成测试：构建产物执行 `--help` 与 `--version`。
- 手工验证：在干净目录按 README 完成一次启动。
- 仓库检查：扫描常见密钥模式和不应提交的文件。

## 10. GitHub 交付物

- 初始化提交与清晰的项目目录。
- README 首屏、产品定位、快速开始和路线图链接。
- CI 徽章及一次成功运行记录。
- Phase 00 Release Notes。
- 30 秒终端录屏：克隆、构建、运行、查看帮助。

## 11. 退出条件

只有在工程骨架、文档入口、自动测试和 CI 同时可用后，才能开始 Phase 01。项目仅能编译但文档或验证缺失，不视为本期完成。

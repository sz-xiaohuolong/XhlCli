XhlCLI — Apple 芯片 Mac 测试版

适用电脑
Mac 配备 M 系列芯片，系统为 macOS 13 或更新版本。
已在 macOS 26.6.2 / Apple 芯片电脑验收；旧版 macOS 尚未实机验收。
本压缩包不适用于 Intel Mac 或 Windows。

打开应用
1. 双击压缩包解压。
2. 将 XhlCLI.app 拖入“应用程序”文件夹，再双击打开。
3. 当前为未经过 Apple 开发者身份签名及公证的测试版。
   若系统阻止打开，先尝试打开一次，再前往：
   系统设置 → 隐私与安全性 → 仍要打开，并按系统提示确认。
   请只对你信任的发送者提供的此应用进行确认。
   如果设备由单位管理且不允许打开，请联系发送者，不需要输入终端命令。

首次配置
1. 点击左下角“设置”，进入模型配置。
2. 选择你使用的服务，例如 DeepSeek。
3. 填写你自己账号的 API Key、对应模型名称和服务地址。
   可沿用页面中的默认地址；模型名称需是你的服务商实际支持的模型。
4. 保存后点击“测试连接”；成功后返回聊天页面。
5. 打开一个准备让助手使用的文件夹，选择模型，即可输入任务。

使用说明
• 无需安装 Java、Node.js 或打开终端；应用已包含运行环境。
• 使用在线模型需要联网、有效 API Key 和相应账号余额。
• API Key 由你自行提供；发送者的账号、密钥、聊天记录不在包内。
• 默认在修改文件或执行命令前请求确认；不确定时请选择拒绝。
• 生成的文件保存在你选定的文件夹中。
• 关闭窗口后应用仍在运行。完全退出请点击菜单“XhlCLI → 退出 XhlCLI”。
• 应用本身不依赖开发工具；若任务需要构建特定软件，该项目仍可能需要自己的工具与依赖。
• “第三方软件”目录是许可与源码材料，不需要安装或打开。

个人数据
设置和聊天保存在当前 Mac 的用户目录中，不会自动与发送者共享。
更换压缩包升级时，退出旧应用，再替换“应用程序”中的 XhlCLI.app。

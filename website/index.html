Multi-Agent 专职协作管线

采用标准 1+2+1 专职架构（Planner 规划师、有界并发 Workers 编码员、专职独立 Reviewer 审查员）。基于 Kahn 拓扑排序算法生成无环任务批次，确保依赖前置就绪与严格质量门禁。

// TeamOrchestrator.java - 有界拓扑批次调度 List<TaskBatch> batches = dagPlanner.planBatches(tasks); for (TaskBatch batch : batches) { batch.executeParallel(workerPool, maxConcurrency = 2); } ReviewVerdict verdict = reviewer.audit(handoffPacket); if (verdict.isApproved()) workspace.commitAtomically();

SideGit 隔离保护快照

在 .xhlcli/snapshots.git 独立裸仓库中物理存储每轮变更，纯 Java JGit 引擎驱动。误删、编译破坏毫秒级原子回滚，主仓库 Git 目录 100% 零污染。

// 物理隔离与纯内存还原 SnapshotRef ref = sideGit.createPreTurnSnapshot(); // 发生误删或编译错误时 snapshotService.revertTo(ref.getCommitId()); // HEAD / index 原样物理恢复
